# Identity Kit: Portfolio Design System

## 1. Typography
* **Primary Font (Headings & Body):** **Inter**
  * *Reasoning:* Inter is a highly legible, modern sans-serif designed specifically for computer screens. Using a single font family keeps the interface extremely clean and technical.

## 2. Color Palette (High-Contrast Dark Mode)
A tight, 4-color palette designed to step out of the way and let the case studies shine.

* **Background:** `#0A0A0A` (Near Black) - *Deep, immersive background that reduces eye strain.*
* **Primary Text:** `#EDEDED` (Near White) - *High contrast for readability without the harshness of pure white.*
* **Subtle UI/Borders:** `#27272A` (Zinc) - *Used for subtle dividers, card borders, and inactive states.*
* **Primary Accent:** `#3B82F6` (Calm Blue) - *Used sparingly for primary buttons, active links, and CTAs. Technical and trustworthy.*

## 3. Logo / Favicon
* **The Logo:** A clean typographic monogram. 
  * **Text:** "GD." or "gandhar."
  * **Styling:** Set in **Inter Semi-Bold**, matching the Primary Text color (`#EDEDED`). No complex graphics—just clean, confident typography.

## 4. Style Note
*A minimal, high-contrast dark mode interface driven by precise typography (Inter). The aesthetic is highly technical and calm, acting as a quiet frame that ensures the engineering work and case studies remain the absolute focal point of the page.*
