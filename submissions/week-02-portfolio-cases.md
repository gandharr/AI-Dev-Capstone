## 1. Interview Copilot
**The Problem:** Recruiters waste hours drafting generic interview questions that don't actually test a candidate's specific skills. The hiring process is slow, manual, and often misses the mark.

**What I Did (And Decided):** I wanted a fast, dynamic solution. I built the backend in Python with FastAPI for speed and integrated the OpenAI API to parse resumes and generate role-specific questions on the fly. I wired it to a PostgreSQL database to track candidate history securely, and kept the frontend clean with React so recruiters could focus purely on candidate evaluation.

**The Outcome:** An AI-powered platform that instantly generates tailored technical interviews and personalized feedback, replacing manual prep work with a seamless, automated workflow.

## 2. PebloAI Workspace
**The Problem:** Context switching kills productivity. People constantly bounce between reading a document in one tab and prompting an AI in another, losing their train of thought.

**What I Did (And Decided):** I built a unified workspace using React and FastAPI. I chose the Google Gemini API for its strong contextual understanding, integrating document summarization and Q&A directly into the writing environment. I optimized the backend to manage real-time prompt interactions efficiently without hanging the UI.

**The Outcome:** A responsive, cross-device workspace where users can research, summarize, and draft content intelligently without ever leaving the page.

## 3. AI Career Recommendation Platform
**The Problem:** Most career advice is completely generic. Job seekers know what roles they want, but don't know the exact technical skills they are missing to actually get hired.

**What I Did (And Decided):** I built a parsing pipeline to extract hard data—skills, education, and experience—directly from uploaded resumes. Using Python and FastAPI, I mapped that data against target role requirements to run a concrete skill-gap analysis, and presented the personalized roadmap through a responsive React frontend.

**The Outcome:** An automated engine that turns a static resume into an actionable, personalized career progression plan with clear steps to bridge skill gaps.

---

## 4. Stellar Vault Manager
**The Problem:** Secure password management is often either too expensive or too clunky to use reliably across multiple devices.

**What I Did (And Decided):** I needed a solution that was highly secure but zero-friction for the user. I chose Next.js and TypeScript for a robust, type-safe frontend architecture. Instead of rolling a custom auth system from scratch, I implemented Firebase Authentication to guarantee secure, persistent sessions and relied on Firestore for encrypted cloud storage.

**The Outcome:** A fast, cross-device password vault that secures credentials seamlessly without compromising on the user experience.
